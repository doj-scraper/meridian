   349→## Phase 1.0: @hermes/event-dsl — Event DSL with compile-time enforcement
   350→Location: src/lib/hermes/event-dsl/
   351→- Canonical HermesEvent interface:
   352→  - eventId: string (UUIDv7)
   353→  - eventType: HermesEventType (MODEL | DECISION | EXECUTION | SYSTEM | TELEMETRY)
   354→  - parentEventIds: string[] (MUST be non-empty for non-genesis events)
   355→  - causalDepth: number (derived: max(parentDepths) + 1)
   356→  - topologicalRank: number (derived from topological sort)
   357→  - payload: Record<string, unknown>

   360→  - runId: string
   361→  - agentId?: string
   362→  - signature?: string (Ed25519)
   363→- NO eventSequence field — permanently eradicated
   364→- Event DSL constructors (the ONLY way to create events):
   365→  - createGenesisEvent(runId, payload) — zero parents, depth=0
   366→  - createModelEvent(parentIds, runId, agentId, payload)
   367→  - createDecisionEvent(parentIds, runId, agentId, payload)
   368→  - createExecutionEvent(parentIds, runId, agentId, payload)
