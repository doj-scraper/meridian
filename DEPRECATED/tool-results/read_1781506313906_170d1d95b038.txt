   145→### Agent Execution Flow
   146→
   147→```
   148→User Clicks "Run"
   149→       │
   150→       ▼
   151→┌──────────────┐     POST /api/agent/run     ┌──────────────────┐
   152→│  Zustand     │ ──────────────────────────── │  API Route       │
   153→│  startRun()  │                              │  run/route.ts    │
   154→└──────────────┘                              └────────┬─────────┘
   155→                                                       │
   156→                                              Create AgentRun in DB
   157→                                                       │
   158→                                                       ▼
   159→                                              ┌──────────────────┐
   160→                                              │  Orchestrator    │
   161→                                              │  .run()          │
   162→                                              │                  │
   163→                                              │  Mode dispatch:  │
   164→                                              │  single/seq/     │
   165→                                              │  group/hier/par  │
   166→                                              └────────┬─────────┘
   167→                                                       │
   168→                                         ┌─────────────┼──────────────┐
   169→                                         │             │              │
   170→                                         ▼             ▼              ▼
   171→                                   ┌──────────┐  ┌──────────┐  ┌──────────┐
   172→                                   │ Agent 1  │  │ Agent 2  │  │ Agent N  │
   173→                                   │ Run Loop │  │ Run Loop │  │ Run Loop │
   174→                                   └────┬─────┘  └────┬─────┘  └────┬─────┘
   175→                                        │             │              │
   176→                              ┌─────────┴──┐   ┌─────┴──┐    ┌─────┴──┐
   177→                              │  Per Step: │   │        │    │        │
   178→                              │            │   │        │    │        │
   179→                              │ 1. Plan    │   │  ...   │    │  ...   │
   180→                              │    (LLM)   │   │        │    │        │
   181→                              │ 2. Execute │   │        │    │        │

   188→                                        │             │              │
   189→                                        ▼             ▼              ▼
   190→                              ┌──────────────────────────────────────────┐
   191→                              │           SSE Event Stream               │
   192→                              │   GET /api/agent/stream?runId=xxx       │
   193→                              │                                          │
   194→                              │   Events: status, plan, action, result, │
   195→                              │   thinking, error, done, reflection,    │
   196→                              │   policy, handoff, group_message        │
   197→                              └──────────────────┬───────────────────────┘
   198→                                                 │
   199→                                                 ▼
   200→                                        ┌──────────────────┐
   201→                                        │  Zustand Store   │

   206→                                        └──────────────────┘

   209→### Policy Check Flow
   210→
   211→```
   212→Agent Wants to Execute Tool
   213→       │
   214→       ▼
   215→┌──────────────┐
   216→│  Policy      │──── Check conditions against tool, role, risk level
   217→│  Engine      │
   218→│  .check()    │
   219→└──────┬───────┘
   220→       │
   221→       ├── ALLOW ──────────────► Execute tool normally
   222→       │
   223→       ├── BLOCK ──────────────► Return error, emit "policy" event
   224→       │
   225→       ├── ASK_USER ──────────► Create ApprovalRequest in DB
   226→       │                          │
   227→       │                          ▼
   228→       │                     ┌──────────────┐
   229→       │                     │  Approval    │──── UI: ApprovalModal
   230→       │                     │  Request     │     (pending in sidebar)
   231→       │                     └──────┬───────┘
   232→       │                            │
   233→       │                     User Responds
   234→       │                            │
   235→       │                     ┌──────┴───────┐
   236→       │                     │              │
   237→       │                  Approved        Denied
   238→       │                     │              │
   239→       │                     ▼              ▼
   240→       │               Execute tool    Return error
   241→       │
   242→       └── SHADOW ───────────► Execute tool + log audit (no block)
   243→```

  1127→
  1128→```
  1129→┌──────────┐     ┌──────────┐     ┌──────────┐
  1130→│  Client   │────►│  Caddy   │────►│  Next.js │
  1131→│  (Browser)│     │  :81     │     │  :3000   │

  1134→Caddyfile Rules:
  1135→  - Port 81 → localhost:3000
  1136→  - X-Forwarded headers
  1137→  - ?XTransformPort=XXXX → localhost:XXXX
  1138→    (for mini-services on custom ports)
  1139→```
  1140→
  1141→### SSE Reconnection Strategy
  1142→
  1143→```
  1144→Connection Lost
  1145→       │
  1146→       ▼
  1147→Attempt 1: Wait 1s → Reconnect
  1148→Attempt 2: Wait 2s → Reconnect
  1149→Attempt 3: Wait 4s → Reconnect
  1150→Attempt 4: Wait 8s → Reconnect
  1151→Attempt 5: Wait 16s → Reconnect
  1152→       │
  1153→       ▼
  1154→Max Attempts (5) Reached
  1155→       │
  1156→       ▼
  1157→Set error state: "Connection lost after 5 attempts"
  1158→```
  1159→
  1160→### Concurrency Control
  1161→
  1162→```
  1163→┌─────────────────────────────────┐
  1164→│    Agent Run Queue              │
  1165→│                                 │
  1166→│    Max concurrent runs: 5       │
  1167→│                                 │
  1168→│    ┌─────┐ ┌─────┐ ┌─────┐    │
  1169→│    │Run 1│ │Run 2│ │Run 3│    │  ← Active
  1170→│    └─────┘ └─────┘ └─────┘    │
  1171→│    ┌─────┐ ┌─────┐             │
  1172→│    │Run 4│ │Run 5│             │  ← Active
