# Task 0.7-b: Agent Canvas V2 Improvements

## Summary
Updated `/home/z/my-project/src/components/agent/agent-canvas.tsx` with all 6 V2 improvements and also updated the companion `agent-node.tsx` to use role-based colors.

## Changes Made

### 1. Role-based node styling
- Added `agentRole` field to node data (from `agent.role || agent.personality` in the store)
- `agent-node.tsx` now imports `getRoleColor` and `ROLE_COLORS` from `agent-canvas.tsx`
- Node border, glow, handle colors, and role badge all use the role color
- Role badge shows a colored dot + role name in the role's color

### 2. Canvas persistence with debouncing
- Implemented debounced (500ms) save to `/api/agent/update` whenever nodes or edges change
- Uses `useRef` for the debounce timer (avoids React hooks lint issue with `useCallback` + external debounce wrapper)
- Persists `graphData` (nodes + edges) to the first agent as canonical store
- Dev server logs confirm PATCH calls working correctly

### 3. FIX C10: Incremental node sync
- Replaced `prevAgentsLengthRef` (count-based) with `prevAgentIdsRef` (Set-based ID tracking)
- On first load: initializes all nodes (restores positions from `graphData` if available)
- On agent addition: only adds new nodes, preserves all existing node positions
- On agent removal: only removes deleted agent nodes and their edges
- On data change (no add/remove): updates node data (label, role, tools) in place

### 4. Orchestration edges
- Defined `ORCHESTRATION_EDGE_STYLES` mapping for 5 modes:
  - `single`: default animated gray
  - `group`: dashed violet
  - `hierarchical`: bold purple
  - `pipeline`: dashed green
  - `mesh`: solid blue
- `useEffect` watches `orchestrationMode` and updates all edge styles when it changes
- New edges from `onConnect` also use the current orchestration style
- Added legend panel (bottom-left) showing the current edge style when not in "single" mode

### 5. Delete agent button
- Added red-tinted "Delete" button in the toolbar (only shown when an agent is selected)
- Calls `deleteAgent(selectedAgentId)` from the store
- Disabled while an agent is running
- Uses `Trash2` icon from lucide-react

### 6. Role color mapping
- Exported `ROLE_COLORS` constant with all 6 role colors:
  - general: #8B5CF6 (violet)
  - planner: #7C3AED (purple)
  - researcher: #22C55E (green)
  - executor: #3B82F6 (blue)
  - critic: #F59E0B (amber)
  - reviewer: #EF4444 (red)
- Exported `getRoleColor()` helper function
- MiniMap uses role-based colors via `miniMapNodeColor` callback
- Selected agent indicator in top-right uses role color
